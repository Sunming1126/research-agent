# 百篇论文库扩容与两轮评测实施计划

目标：建立项目内恰好 100 篇、跨学科、可核验的 PDF 论文库；修复第三轮揭示的综述事实覆盖与大库检索瓶颈；使用新论文库完成两轮 A–E 本地诊断评测。

## 文件分工

- `paper_library/pdfs/`：真实 PDF，本机测试材料；不纳入 Git 或 Docker 构建上下文。
- `paper_library/manifest.json`：逐篇 arXiv 来源、标题、分类、文件名、大小、页数和 SHA-256。
- `scripts/build_paper_library.py`：遵守 arXiv API 限速，下载、校验、断点续跑并冻结清单。
- `src/research_agent/rag/retrieval.py`：按论文先召回，再为每篇选证据片段；支持题目指定论文的稳定覆盖。
- `src/research_agent/workflows/tasks.py`：C 类按题目维度生成事实覆盖清单；缺失项定向补证据后写作。
- `evaluation/library_benchmark.py`、`evaluation/run_library_rounds.py`、`evaluation/score_library_rounds.py`：两套题目、真实运行和评分。
- `docs/2026-10-17-百篇论文库两轮评测.md`：逐轮分数、反思和后续事项。

## 实施与检查

1. 先为百篇库检索漏召回、综述关键事实漏覆盖写针对性测试，确认现有实现失败。
2. 改造检索与证据覆盖；新旧项目测试必须通过，授权路径仍按 `materials` 隔离。
3. 通过 arXiv 官方 API 从 2023–2025 年论文中选择跨学科候选；下载时核验 PDF 魔数、可抽取文本、页数、哈希和唯一编号，最终恰好 100 篇。
4. 两轮各 A–E 五题，B 候选为全部 100 篇，C/E 每题仅授权指定论文，D 使用公开 D-04、D-05；结果与评分保留独立目录。
5. 对每轮 C 事实与 E 要点人工复核，按赛事公开公式计算本地诊断分；检查 10 题状态、结果文件回读与产物哈希。

边界：本地两轮每类只一题，分数不是正式 25 题榜分。公开 D 小实验不等于对应论文原始实验；时间/吞吐指标跨环境只作诊断。论文原始 PDF 仅用于本地研究测试，不随代码或镜像再分发。
