# 科研助手 v3 适配与三轮真实公开样例测试报告

日期：2026-10-21

## 适配内容

- dispatch 支持 `schema_version: 3`、`research-assistant-objective-v3`、A/B/C/D/E=1/3/2/3/2 和 11 个题号。
- 题号支持两位或三位后缀，并校验 v3 D 类 `difficulty`。
- 整轮汇总和预检查按当前 dispatch 动态计数；旧 v2/25 题仅保留兼容测试。
- D-01、D-02、D-05 增加标准算法实现：TF-IDF 软最大分类、分组稳健 BM25、FIFO/加权公平调度。
- 平台 runner 使用 `--case <case_id> --implementation <源码路径>`，源码复制到本队工作目录并记录哈希。
- 同时兼容 RPC `complete`、客户端直接输出最终答卷、答卷 `completed/failed/materials_missing` 三类状态。

## 三轮真实公开样例

测试命令：

```powershell
$env:PYTHONPATH='.;src'
python scripts/run_v3_public_three_rounds.py
```

输入来自新版官方 `科研助手赛题材料/x新/research-experiments/公开样例请求/` 和三题 `sample.json`，没有使用假数据或模型模拟。每轮运行 D-01、D-02、D-05 各一题，并执行 JSON 有限值、结果长度、排名完整性和 D-05 任务守恒校验。

| 轮次 | D-01 | D-02 | D-05 | 结果 |
|---:|---|---|---|---|
| 1 | 不均衡、重复词、标点 | 空字段、重复未知词、不等组 | 并发预留 | 通过 |
| 2 | 均衡、空文本、未知词 | 独立 rank 默认输入 | 过期与同时到达 | 通过 |
| 3 | 官方基础 sample | 官方基础 sample | 官方基础 sample | 通过 |

汇总文件：`output/v3-public-three-rounds/summary.json`。

## 回归与环境记录

- v3 专项回归：`11 passed`。
- `compileall`：通过。
- 300 篇论文库完整性校验：`300/300`，10 个领域各 30 篇。
- 项目测试（加载 `local-workspace/python-deps`，排除已知 `test_gateway_retry.py` 二进制兼容项）：`63 passed, 5 skipped, 2 failed`。两个失败均为本机条件：Windows 禁止测试 HTTP 端口（`WinError 10013`），以及本地 Pillow 缺少 `_imaging` 二进制；不涉及 v3 算法或 dispatch 逻辑。
- 未把全量 pytest 扫描到的 `local-workspace` 依赖/参考项目测试计入项目结论。

## 结果边界

这三轮是新版 D 算法和公开输入的真实离线验证，证明算法内部接口、边界处理和输出结构可运行；它们不包含平台私有标签、可信 RPC 回执、官方图表采集和正式榜单计分。正式平台仍需在挂载 `run_experiment.py`、Unix 会话和本队授权材料后验证。

## 仍需平台确认

1. 官方平台实际挂载的 r3 runner 与本地公开包摘要一致。
2. 平台对本队源码的隔离、源码哈希和 180 秒整题限制。
3. 私有 D 数据、真实图表归档和部分完成分的最终回执。
4. 赛事模型网关、API 配额和正式派题材料。
