# 新版官方科研助手材料对照

检查目录：`科研助手赛题材料/x新/`（v3/r3）

后续修订：`科研助手赛题材料/x新/research-experiments-20261020-source-v1/`

检查日期：2026-10-20

## 结论

`x新` 是新版官方联调材料，不是原目录的重复下载。核心文档已经升级到 `research-assistant-objective-v3`，正式派题为 11 题；D 类公共实验包升级到 `d-materials-20261019-r3`，协议为 `layered-d-v3`。

2026-10-20 的 `source-v1` 不是算法协议重写，而是在 r3 基础上新增 `d-model-source-v1` 源码来源准入：正式 D 源码必须由当前题、当前会话的 Gateway 完整生成，经过 `/source` 凭证核验后才能 `/run`。完整对照见 [source-v1 影响分析](2026-10-21-source-v1影响分析.md)。

## 文件核验

对旧目录和 `x新` 做了相对路径 SHA-256 对照：

- 旧目录文件：67 个；新目录文件：57 个；
- 共同文件中 5 个内容发生变化：三个科研助手主文档、D 类 README、D runner；
- `x新` 新增 52 个文件，主要是 D-01/D-02/D-05 的新版协议、实现入口、worker、图表框架、公开边界输入和判分说明；
- 新包 `PACKAGE_MANIFEST.json` 声明：`document_revision=d-materials-20261019-r3`、`protocol_identity=layered-d-v3`、`seed=42`、`runtime_helpers_changed=true`；算法方法和评分公式保持不变。

## 对当前 Agent 的直接影响

上述切换已经在 2026-10-21 完成：

1. `src/research_agent/core/dispatch_plan.py` 按 v3 读取数量对象并动态校验 11 个 case；`dispatch.py` 和整轮汇总不再把 25 题当作正式固定值，旧 v2/25 题仅保留兼容测试。
2. `src/research_agent/core/engine.py` 的整轮汇总和预检查按当前 dispatch 的实际题数校验。
3. `src/research_agent/workflows/layered_d_runner.py` 已为 D-01/D-02/D-05 请求当前题 Gateway 生成并原样保存 `implementation.py`，调用 `--case` 与 `--implementation`，并保存回执、图表和哈希证据；正式运行仍必须由平台挂载新版 runner。
4. `src/research_agent/workflows/d_algorithms/` 仅作为公开离线算法夹具；正式路径改为 `source_generation.py` 调用当前题 Gateway，Docker 构建排除这些完整算法源码。三轮离线测试验证算法与边界，不等同于平台私有标签、可信回执或正式榜分。

A/B/C/E 的外层结果字段和主要方法没有被新版材料改变，但 C/E 的正式判题仍以新版 v3 文档为准。
