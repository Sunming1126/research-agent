# 2026-10-22 三轮仿真与逐轮优化

## 范围与评分方法

每轮按 v3 的 A/B/C/D/E = 1/3/2/3/2，共 11 题派发。真实调用本地已配置模型，执行授权公开离线实验，保存 JSON、Markdown、图表、运行回执并回读校验。三轮使用相同冻结题材，便于隔离版本变化与模型波动；不代表对未知正式题的独立泛化证明。

此前的 88.60 分包含历史 C/E 审阅记录与关键词筛查，不能与本次的新裁判分直接相减。新版裁判只审阅本次正文，使用固定 rubric、段落编号、原文证据 ID、正文 SHA-256 和裁判源码 SHA-256；完整支持才给整项分，部分支持不给整项分。旧答案另行复核且不改写原始分。

C/E 是模型代理审阅，同一模型参与生成与评审，仍有偏差和随机性；A 为字段检查，B 为冻结文件集合匹配。D 使用旧版公开离线 runner 的证据量表，性能相关分受主机时延影响。正式平台的来源凭证、受控运行可信分、专家及 Token 复核未在本机模拟，分数不等于官方榜分。

## 第一轮前的优化

- 长文检索由单一主题召回扩展为主题、方法、实验、局限多路补充，每篇最多八个候选片段，不按固定论文名补答案。
- 提取事实增加方法组成、变体、数据、基线和适用限制覆盖；仍要求摘录来自授权原文，证据不足允许少取。
- Idea 写作和审查共用基线、命名基准、预算控制、划分、防泄漏、指标和证伪检查清单。
- 每轮分别保存输入、实际运行的 Agent 源码快照及摘要，不覆盖旧结果。

## 第一轮复盘与后续修复

- B-03 的模型返回列表包含否定理由：理由已经写明论文为题目排除项，但仍被纳入提交。新增明确否定理由和文件名具名排除项检查；不因论文正文提及被排除方法就误删。
- 裁判曾把多个原段落改写拼接成摘录，严格连续原句核验因此拒绝得分。改用程序生成段落编号、程序回填原文，原始评分仍保留；统一对旧答案和第一轮另行复核。
- 裁判曾将并列事实中的部分支持算为完整支持。冻结 `segments-full-coverage-v2` 协议，要求显式区分 full/partial/missing，并新增部分事实不给整项分的回归。
- 对更复杂题目的延伸风险：论文把排除方法作为对照时不应被误删；比较论文自身贡献与相关工作时可能误归因；实验建议必须提供可执行的参数与统计方案。

## 第二轮复盘及升级

- B 类三题均为 15 分，第一轮出现的明确排除项误收得到修复。
- E-02 因首稿审查后预算不足，转为确定性保底；虽然文件和引用合法，设计内容过泛，代理分仅 1.5/15，拖低 E 类平均分。
- 升级：提取请求只发送片段编号、页码、标题和正文，文件哈希、偏移等保留在本地；首稿输出上限由 6500 调低到 4200，动态预留预算；审查增加原文摘录对照；审查历史完整保留，避免只看到最后一个预算错误。
- 延伸处理：Idea 的统计设计需明确重复次数、参数范围和预算；置信区间包含零应写为证据不足，不能直接宣称假设被证伪。

## 第三轮复盘及升级

- C-01 单题用量为 27852 Token，较第一轮同题 32508 降低约 14.3%；但全轮仍出现两次预算保底，不能据此宣称资源问题已经解决。
- C-03 与 E-01 的完整首稿审查指出方法归类或范围限定问题，整篇改写后没有足够预算再次审查，分别转为保底，得 19/25 与 9/15。
- B-01 出现新的否定表达“按题目排除”，此前规则只识别“明确排除项”，导致两篇无关论文混入，得 13.5/15。
- 升级：扩充否定表达检查；检索提示明确要求不相关项直接省略，并接受 `relevant=false` 的拒绝信号。具名排除采用完整方法名匹配，防止排除 RAG 时误删 Self-RAG；论文正文仅提及排除方法不触发删除。
- 升级：修订改为最多五处精确原句替换。原文必须在当前稿中唯一出现，未知文本、歧义替换和无变化修订一律拒绝；首稿整篇审查，修订稿只核对变更及全部已知问题，同时仍对整篇执行长度、引用与证据 ID 校验。
- 升级：方法、实验和局限检索增加中文术语，避免策略仅适用于英文论文。源码升级至 `0.3.1`。
