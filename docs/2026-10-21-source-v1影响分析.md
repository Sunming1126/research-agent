# research-experiments-20261020-source-v1 影响分析

日期：2026-10-21

对比目录：

- 旧版：`科研助手赛题材料/x新/research-experiments`
- 新版：`科研助手赛题材料/x新/research-experiments-20261020-source-v1`

## 结论

新版不是算法协议升级，而是 **D 类源码来源准入升级**。D-01、D-02、D-05 的方法、参数、公开输入、算法内部返回结构和评分公式保持不变；正式运行代码的来源发生了实质变化。

## 文件级差异

新增文件：

- `Agent适配与源码来源要求.md`：规定当前题 Gateway 生成、完整源码保存、模型修复、源码凭证和锁源流程。
- `报错对照与测试清单.md`：增加 `D_SOURCE_*` 来源拒绝、凭证、锁源和审计故障排查。
- `model_source.py`：离线提取唯一完整源码的工具；只做 UTF-8、Python 3.9 语法和 `run_experiment` 入口检查，不联网、不签发凭证。

变更文件：

- `run_experiment.py`：新增 `/source` 来源核验流程；当 `RESEARCH_D_SOURCE_PROVENANCE=d-model-source-v1` 时，先提交源码申请 `source_credential`，再用凭证调用 `/run`。
- `PACKAGE_MANIFEST.json`：版本变为 `20261020-source-v1`，新增 `source_provenance_version=d-model-source-v1`、`source_admission_is_new_requirement=true`。
- `README.md`、`版本说明.md`、运行指南、D 类要求和参赛导航：全部改为源码来源修订版说明。

未变化：

- 三题目录内的 `method.md`、`protocol.json`、`sample.json`、公开样例请求、逐题 manifest 和算法参数。
- `layered-d-v3`、seed=42、Python 3.9、1 CPU、1024 MiB、每阶段 20 秒、整题 180 秒。
- 每题 40 分、三项指标和最终答卷字段。

## 对当前 Agent 的影响

旧实现“镜像内预置完整算法→复制到 `implementation.py`→调用 runner”在新版正式评测中会被来源核验拒绝。一次无关模型调用也不够，平台要核对提交源码是否匹配当前题、当前会话的完整模型回复。

当前代码已增加：

1. D 类当前题材料读取：`method.md`、`protocol.json`、`sample.json`。
2. 当前题 Gateway 的完整 completion 调用，保留 `finish_reason` 和完整 assistant 正文。
3. 唯一完整源码提取：拒绝截断、多版本、缺少 `run_experiment(request)` 或 Python 3.9 不可解析的响应。
4. 原样保存 `generation-response.json` 和 `implementation.py`，记录源码哈希。
5. 正式 D runner 继续调用新版 `/data/experiments/run_experiment.py --case ... --implementation ...`，由平台客户端完成 `/source` 凭证申请。
6. Docker 构建排除本地完整算法夹具；公开离线测试仍可使用这些夹具验证算法边界，但不能用于正式来源证明。

## 正式运行边界

- 当前题 Gateway 必须使用平台注入的地址、凭据和模型，不能用个人 API 地址替代，也不能跨题复用响应或凭证。
- `finish_reason=length`、回复中出现多个不同实现、源码被本地添加注释或格式化，都应重新请求模型返回完整源码。
- 锁源前可让同一题模型返回完整修复版本；锁源后只能用同一源码幂等恢复，不能换源码重跑。
- 本地公开样例、源码语法检查和 `model_source.py` 不会签发正式凭证，也不产生正式成绩。

## 已做的适配验证

- 源码提取单元测试覆盖完整代码块、截断、多版本和 UTF-8 保存。
- Gateway 源码生成测试覆盖当前题材料拼接和原样保存。
- 原有 v3 D 公开样例算法测试仍保留，作为离线算法夹具测试，不再被当作正式来源证明。
- 当前项目回归：`68 passed, 5 skipped, 2 failed`；两个失败仍是本机 Windows 端口权限和 Pillow `_imaging` 二进制问题，非源码来源或 v3 逻辑失败。
