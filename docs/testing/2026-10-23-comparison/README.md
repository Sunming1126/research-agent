# 双镜像独立对照（2026-10-23）

本轮比较直接运行两个完整发布镜像，未覆盖队友版本。详细结论见[对比报告](双版本对比报告.md)，机器可读结果见[summary](comparison-summary.json)。

现有版有效 A/B/C/E 8/8、两轮D各13/13公开输入；队友版有效A/B/C/E 7/8、首轮D两题被内部自测拒绝，次轮D05出现丢弃原因顺序错误。被拒绝的两份原始代码在独立Python3.9中通过六个对应输入；两镜像交叉自测都拒绝，属共有兼容性风险。队友版另有取消和错误分类质量问题。原始两篇C02为测试设置错误，与五篇合规C02失败严格区分。

每轮失败、诊断与成功均保留；没有官方成绩或完整正式准入结论。原生Harness会话留在测试机，去账号配置的请求/回复、源码、输出与复跑工具见[证据Release](https://github.com/Sunming1126/research-agent/releases/tag/test-comparison-v041-20261023)。

用户已要求后续取两版优点合并；这次对照是合并前基线，下一轮新镜像须单独打标签复测，不回改本轮结论。
