# R1：C/E 正式硬规则适配闭环

2026-11-02。起点为队友 `codex/friend-development@cd733b2`，本轮修改位于独立协作分支 `improve/score-compat-20261102`。采用范围为待评审候选，未覆盖队友分支、未部署或上传评测。

## 观察—假设—实验—结论—决策

**观察。** 用户提供的 ce-quality-v3 规则为 C 正文最多 5000 字符、E 最多 4500 字符，标题行和参考文献节不计上限；C 每组数字引用计一次、最多 40 次。起点源码仍采用 C4500/E6000，并把组合引用的每个论文编号计入次数。E 专用生成与恢复提示也仍允许 6000。历史官方 C01 反馈确认本队自检抛错，但没有字段、答卷或底层日志，不能把本轮边界复现称为该线上故障唯一根因。

**假设。** 旧规则会错误拒绝合法 C 稿、错误接受超限 E 稿，并使组合引用消耗多份次数。只同步硬规则及相应提示，不变更研究内容、模型、预算或恢复次数，可消除这些确定的兼容风险。

**实验。** 冻结 23 项边界与故障用例，在未修改的队友源码和候选上执行相同测试：包含 C4501/5000/5001、E4500/4501/6000、标题及参考文献、40/41 组引用、引用身份保留、代码围栏中的伪标题，以及超长 E 首稿恢复和持续不合格拒绝。

| 范围 | 结果 | 执行性质 |
| --- | --- | --- |
| 原版 23 项同例 | 12 通过、11 失败 | Codex 明确授权的离线 C/E |
| 候选同例 | 23 通过、0 失败 | Codex 离线 C/E |
| C/E 相关回归 | 182 通过、0 失败 | Codex 离线 C/E |
| 最终全量源码回归 | 480 通过、1 失败、6 条件跳过 | 原 Harness 固定总控原生执行；合成模型响应 |
| 原版唯一剩余反例重放 | 0 通过、1 失败 | 原 Harness；未修改队友源码 |
| 官方 SDK 本地 HTTP 契约 | 12 通过、0 失败、0 跳过 | 原 Harness；真实 SDK、合成模型响应 |

全量唯一失败为 `test_output_mounted_library_is_selected_without_searching_team_directories`：Windows 下授权文件的绝对路径包含盘符/反斜杠，被现有材料校验拒绝。原版同一用例、同环境已独立复现，不是 R1 新增回归；本轮不把它跳过、不修改共享材料解析器，仍记为未解决。6 条跳过涉及 Windows 符号链接/大小写/Unix socket 和未安装的 300 篇库，不计为通过。

**结论。** R1 解决已证实的字数及引用次数错位，23 项同例从 12 到 23 通过。E 超限稿被校验拦截，允许有界模型重写，持续不合格仍报真实失败。12 项 SDK 测试覆盖 C/E 恢复、额度/持续坏稿失败、B 响应及追踪，均通过。目标模型调用为 0，不存在可报告的真实模型耗时、Token 收益或官方提分结论。

**决策。** 保留为可审查候选，提交独立 R1 修复；下一因素只处理单题限时一致性。不宣称整体全绿或保证不失分；Linux 镜像、真实模型多轮与正式平台验收仍待执行。73.9 分是用户已有评测，86 分是历史峰值，均不被本地测试替换。

## 修改边界与证据

- 新增 `contracts/report_rules.py` 集中硬规则；6 个必要 C/E 接点同步限制和提示。A/B/D 算法、模型接口、SDK、依赖、调用/Token 上限、C1 恢复策略不改。
- `report_citations()` 的论文身份枚举、事实支持和原文核验保持；组合计数只服务于上限判断。标题只识别实际输出采用的 Markdown ATX 标题，代码围栏里的 `#` 不当标题排除。
- 原有冻结 hash 清单原样保留。测试对必要改动做精确逆向投影，比较其他 AST 节点，不能以整个文件豁免绕过隔离；旧提示断言按用户给出的新规则显式更新。
- 历史测试夹具的 `/real-papers`、`/materials`、`x新` 路径改为明确公开材料配置，原缺失提示词快照绑定已提交版本 `04216cf`；D 后处理测试补齐起点已要求的公开前置材料。未改生产 D 逻辑，也未改期望的真实失败/部分结果语义。
- 所有受限运行、失败、超时和重跑保留在本机 `镜像测试/runs/score-*`；失败不能因后续通过而删除。机器结果、失败名及原始日志 SHA-256 见 [证据索引](evidence/index.json)。原生会话完整日志不发布到 GitHub。

在项目原环境运行 `python -m pytest -q tests/test_current_ce_limits.py`；官方 SDK 契约入口为 `tests/test_c201_http.py`、`tests/test_e4_http.py`、`tests/test_b5_http.py`。测试使用合成响应，不能代替真实模型质量评价。用户指定的后续执行仍应放在原 Harness 工作区/总控，例外范围按工作区 AGENTS.md。
