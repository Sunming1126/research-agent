# 执行协议与验收门禁（评审草案）

## 阶段边界与单因素原则

G0当前仅交付诊断和矩阵。评审通过后，P0按“隔离复现→一个修复因素→影子对照→候选验收→阶段评审”执行。P0通过后才进入P1；P1通过后才进入P2。每次候选明确改动因子、源码SHA和对应注入ID。P0内若先做契约恢复，再做耐久性，再做幂等，须分别留对照和结论，不能一次改完后将收益归给其中任一项。

所有Agent测试协调器、离线注入、真实模型和复测均由原DeepSeek Harness工作区/固定总控执行，magic优先；本阶段直接执行的脚本只做文件读取、哈希、AST清单和文档生成，不执行Agent、不冒充原生测试。之前Codex离线例外仅覆盖当时B专项，不外推到本轮C/E/D。原生会话不能操作时保留待执行，不启动headless调用或新工作区。

## 稳定内核与受约束动作库

复用当前官方Runtime、派题核验、授权检索、证据核验、报告生成和暂存/发布/取消锁；不新增总体框架。恢复策略只返回下列动作建议，内核独立校验前置条件、当前题身份、Schema、动作次数、预算和状态。策略不能写正式答案或绕开内核。

| 动作 | 使用前提与边界 | 不允许的行为 |
| --- | --- | --- |
| R0 正常交付 | 当前题候选通过完整契约/证据/文件校验 | 只检查JSON可解析就交付 |
| R1 重新封装 | 正文和证据已经合格，只修复程序负责的case_id/path/包装类型 | 修改论文事实、补造证据、改D原样源码 |
| R2 完整重生成或局部修订 | 已分类的可恢复模型/内容错误，原有两次生成上限内，当前材料/预算可用 | 无限重试；额度耗尽仍反复调用；未经校验截短/拼接正文 |
| R3 重试存储 | 同一已验证候选，确定的瞬态存储错误，建议上限两次，需本评审确认 | 存储失败重新调用模型或无限等待 |
| R4 重放已提交结果 | 同一传输实例、会话与输入/材料/Schema哈希，收据完整、哈希匹配；先核验SDK能力 | 按case_id命中跨轮缓存；复用其他正式评测源码或Gateway证明 |
| R5 补偿/回滚 | 提交未完成，当前请求拥有产物；持久化日志说明原状态 | 误删其他请求/上轮证据；回滚失败还记成功 |
| R6 交付已验证当前稿 | 生成链中确有合格候选，身份/内容不变，审查不完整须明确记录 | 把未审或被拒稿标成语义审查通过；将保留稿称作内容一定满分 |
| R7 明确失败并停止 | 无合法稿、身份冲突、越权、不可恢复存储/额度/硬超时 | 空JSON/通用模板/虚构参考文献伪装成功 |

每个动作记录：request实例、输入/候选SHA、phase、failure_class、action_id、reason_code、attempt、预算前后、前一状态、后一状态、主错误和补偿错误。重复动作有次数限制，死循环与未知动作直接拒绝。恢复策略的建议不是执行授权；内核护栏始终强制。

## 指纹与审计格式

每个题实例记录：原始HTTP字节SHA256；八字段canonical JSON SHA256（固定键顺序、UTF-8，保留正文/数组/Unicode值）；assigned和dispatch原始SHA；解析结果与原文件对应；每个授权材料相对路径、大小、SHA；实际请求使用的prompt/模型配置版本；Schema/规则/实验协议SHA；镜像tar与配置摘要、Git应用树SHA；Python/SDK及依赖锁、平台、CPU/内存限制、locale/TZ、允许的非秘密预算开关、缓存版本和冷/暖状态。

平台注入ID、模型会话、传输Idempotency-Key、工作目录RWT分别存储，不把同cwd当会话归属证明。正式trace_id只使用SDK原值；不可得写null及原因。环境指纹使用白名单，不能读取/散列凭据、cookie、完整env或把个人配置加入证据包。服务器返回的模型ID/配置不可得时明确unknown，不以本机magic配置推定平台模型。

未来每个注入独立保存 `input-fingerprint.json`、`environment-fingerprint.json`、`decision-trace.jsonl`、`schema-diff.json`、`transaction-journal.jsonl`、产物/响应哈希与原始错误。HTTP原文与模型回复只保留在既有授权范围的本地证据；共享报告先脱敏。平台不开放的原日志/响应标not_available，不补造。

## 发布事务与远端确认

建议在现有暂存/锁/回滚基础上增加持久化提交清单，不先引入新数据库依赖。每个题实例：`VALIDATED → PREPARED → PUBLISHING → LOCAL_COMMITTED → WIRE_SENT`；异常进入`ABORTED`、`ROLLBACK_FAILED`或`RECOVERY_REQUIRED`。REMOTE_ACK单独记录confirmed/unknown，仅有权威平台确认才能confirmed。

1. 完整答卷预检；将MD、JSON、收据及内容哈希写同文件系统暂存区域。
2. flush、文件fsync、读回及内容一致性检查；提交日志包含旧/新产物哈希和补偿方案。
3. 持当前请求发布锁，沿声明顺序rename；在Linux目标文件系统验证目录同步能力，提交清单持久化后才LOCAL_COMMITTED。
4. 任一发布失败执行补偿并记录二次错误。进程重启先按日志恢复/隔离未提交状态，再开放当前实例回放。
5. 仅发送LOCAL_COMMITTED的结果；同一实例响应丢失重试应回读验证结果，不重新生成。

文件内容读回不等于断电耐久；单文件replace不等于MD/JSON/收据多文件原子。固定官方多路径协议不能凭空增加跨平台事务。需验证平台是在完整HTTP响应后读取产物，若平台允许提交窗口并发读取，还需双方明确读取屏障；无此证据不声称外部读者始终只见一致状态。

Agent是`/solve`响应方，没有证据表明可主动调用额外“提交确认”API。HTTP发送成功也不能证明平台已归档/判分，确认未知时不得回滚已发出的完整答卷或伪造确认。幂等验收是同一题实例的副作用去重与可验证回放，不承诺跨网络恰好一次接收。若同键不同输入明确冲突；新正式会话必须新执行。

Python官方说明缓冲文件需先flush再fsync，replace成功才提供该次rename的原子性，跨文件系统可能失败。Linux耐久性与Windows能力分开实测，不以Windows通过替代Linux容器门禁。[fsync说明](https://docs.python.org/3/library/os.html#os.fsync)、[replace说明](https://docs.python.org/3/library/os.html#os.replace)。进程kill测试只验证进程中断恢复，不能标成真实掉电测试。

## 影子、灰度及回滚

- 影子阶段：旧版保持正式目录所有权；新策略先对固定模型响应/输入重放，只写当次测试work子目录，记录“将选择哪个动作”，不改正式答案。零模型重放不能代替真实生成稳定性。
- 本地灰度：原Harness通过官方Runtime启动Linux候选，按矩阵逐个C/E和完整11题验收；候选标识、默认关闭策略开关、回滚镜像SHA固定。每个评测实例开始前选定版本，不能在同题执行中切版本。
- 平台灰度：只有阶段评审批准后才准备单次测试评测，不自动打榜或加次数。平台缺少流量分流能力时，用明确单轮试验和可恢复旧包替代虚构的百分比canary。
- 遇到新增契约违约、身份/材料越权、重复副作用、脏文件通过校验、虚假确认/trace、失去取消或回滚护栏，立即停止候选推进并回滚策略，不掩盖失败。不仅以总分下降判断。

## 采样、资源与统计

先执行无模型注入/契约实验；过门禁后初始真实模型比较建议三组新旧配对，每组同11题，共66题实例，轮序预注册为旧→新、新→旧、旧→新；固定A题、材料和评分版本，冷/暖缓存分别成组。模型使用新的实际生成，不把回复重放叫作真实重复。输入或环境漂移的轮次不配对，但原失败保留并单列；不任意删低分轮。

资源仅作准备估计：若每轮接近既有86分轮139,326 Token、27分29秒，六轮约835,956 Token、2小时44分54秒；真实成本可能不同，总控和独立裁判另计。初始三组的分位数与方差仅探索性。是否增加到十组配对在初始结果评审时决定，不能以不足样本声称论文级统计显著或无限扩跑。

总分固定按类别均值求和；失败/未交付计零进入实验比较的统一分母，尚未完成的轮次不发布为完整总分。平台自身未生成成绩或声明不计成绩的记录保留为incomplete，不伪造官方零分。须同时报告条件指标与所有尝试的硬失败分母。

输出每版本各轮总分、P05/P50/P95（预注册nearest-rank，n很小时注明极值性质）、最差轮次、每题有效交付率与正确性/事实支持、schema违约率、整题零分率、硬失败率、恢复成功率、回滚尝试/成功/失败率；同题重复重放不是新题实例。耗时P50/P95、Token/调用/消费分别记录，未知用量不得填0；安全拒绝或成功回滚不计答题成功。报告0/n观察值与样本量，不把零次观测当成总体概率为零。

D工程收敛目标建议：固定逻辑输入/回复下轨迹与源码选择100%一致；固定真实输入重复下逐题方差至少下降50%，同时平均、最低分及失败率不退化。控制方差为0时要求候选亦为0，不计算除零比率。样本不足只记工程观察，不声称显著；统计显著性待足够配对样本及评分可比后给区间。这里是待评审门槛，未产生D改造结果。
