## 已知缺陷与量化口径

- 冻结的D05三项协议缺陷探针，来自两个保持原字节的历史模型程序：3/3拦截，100%。仅限这个明确样本集，不代表全部未知错误。
- 历史真实修复样本很少且题目/探针不同：v14触发修复3题、外部全部公开检查恢复1题（33.33%）；hybrid-v1触发2题、内部恢复2题，但独立外部全部恢复仅1题（50%）。不能据此声称稳定提高16.67个百分点。
- 单个真实子进程取消夹具从3.167秒降到0.356秒，减少88.76%；这是受控夹具，不是D05历史卡死的完整根因证明或线上p95。
- 额度错误夹具修复后只做1次完整生成，避免最多2次无效尝试；没有测量真实费用降低比例。
- 主轮记录中PASS/FAIL/BLOCKED有依赖关系和覆盖差异，按全部记录和按已执行项的分母分别给出，不当作独立正式题目通过率。
