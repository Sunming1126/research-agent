## 已落地的优势

1. **提交状态更可靠。** JSON、Markdown与收据在本次work中先准备、核验再发布；失败或取消撤回本次部分发布。重试归档旧结果与收据，已完成B结果不会被稍晚诊断失败清空。原main与0.4.14的同组六条故障反例从0通过/6失败变为6通过；本版保留这些修复。范围是进程内故障处理，尚未证明掉电或强杀后的完整事务恢复。[证据](testing/2026-10-27-stability-and-retrieval/验收结果与量化.md)

2. **B检索更完整。** 保留文档级排序融合、多条件候选、连续证据窗口和明确数量约束；深页探查只在获准PDF内进行，继承同文档前页参考文献状态，识别分行附录标题，并用Chunker版本隔离旧缓存。0.4.17与0.4.19在同60篇论文的10条固定字面查询上为8/10→10/10；最终3题×3组交替重复为5/9→9/9。数据属于字面证据诊断，0.4.20保留B实现，不作为新的真实模型成绩。[证据](testing/2026-10-29-b-stability-closure/本轮实验闭环与交付决定.md)

3. **C恢复路径能修复整份响应错误。** 首稿的used_evidence_ids为空/未知，或含重复未知内部证据标记时，正文patch无法直接更新这份元数据。0.4.20在原有两次上限内改为完整响应重生成；合法绑定继续沿原路径，持续无效仍拒绝。严格反例用唯一合法标题patch排除夹具自身错误，旧版2/5通过、候选5/5通过；源码完整回归402通过、0失败、0错误，6环境跳过与1已知strict xfail。原Harness四次调用的失败与通过均保留，目标模型调用0。[证据](testing/2026-10-30-c-response-recovery/C类修复与验证报告.md)

4. **核验过程可追溯。** 授权PDF/源码/测试/产物按SHA-256关联，原始失败、模型原文、无效摘录、修订与收据分别保留。引用检查、审查和归因使用统一引用语法；跨片段摘录只按同文档哈希与连续偏移恢复。新增镜像的41份Python应用文件已独立回读匹配最终回归指纹。[镜像记录](submission/2026-10-30-0.4.20-C/交接.md)
