## 三类职责

| 层级 | 职责 |
| --- | --- |
| 选手Agent | 读取当前题材料、生成/组织本队源码、管理模型与实验时间、调用正式客户端、返回真实答卷 |
| 选手算法run_experiment | 按本题协议从request数据计算预测/排名/轨迹；不直接填写最终指标，不联网调用模型 |
| 平台正式执行与判分 | 隔离执行、独立计量、制图归档、身份和源码绑定核验；公共绘图函数本身不能证明真实性 |

## 平台调用

```text
python /data/experiments/run_experiment.py --case D-05 --implementation <本队源码绝对路径>
```

D-01/D-02替换case参数，三题均须提供源码。客户端依赖平台当前题授权Unix会话；普通电脑直接运行不能启动正式平台实验。本地样例使用指南中的worker路径。

最终答卷仅case_id/status/metrics/figures，恰好三个完整指标对象。未完成时保留name、unit及其他字段，未知数值填null；不要把整个指标对象写成null。真实部分图可以保留，没有实际图片时figures=[]。completed只能表示所需实验完成，不能因进程退出或图片打包成功就填写。

## 时间与完整性

Agent整题/solve时限180秒；每个正式算法阶段20秒、1CPU/1024MiB。客户端600秒通信设置不延长整题。为正式实验、落盘和返回预留时间，结果未知时不盲目重发正式实验。

每题manifest记录本版9个原运行文件的摘要，PACKAGE_MANIFEST记录整包除自身以外的文件摘要。它们能检查字节一致性，不是数字签名或可信实验回执。本版三题逐题材料与同步时正式挂载版本一致；未来仍应核对平台当次挂载材料。

公开包不含私有实例、隐藏测试标签、完整参考算法、预生成模型或结果、签名密钥、管理员判题器。公开训练/开发标签是合法输入；公开样例通过不代表完整正式得分。
